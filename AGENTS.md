# TaskFlow API

## 1. Project Overview

TaskFlow API is a REST API for collaborative project and task management.

The application allows users to:

- Register and authenticate.
- Create and manage organizations.
- Invite existing users to organizations.
- Create projects within organizations.
- Manage project memberships.
- Create, assign and track tasks.
- Monitor project activity and progress.

The goal is to build a maintainable, secure and well-tested backend using modern Python technologies.

## 2. Technology Stack

Use the following technologies unless explicitly approved otherwise.

- Python 3.12+
- FastAPI
- Uvicorn
- SQLAlchemy 2.x
- PostgreSQL
- Pydantic v2
- Alembic
- Docker
- Docker Compose
